# Python-Practice
Small Python exercises and experiments as I learn — built around my own memory-system code.

## Current Focus

**Parallel OOP track (Modules OOP-01 through OOP-05)** — focused practice on class design for the Anthropic Fellowship Pre-Screen, where the test is *"design a system from scratch under progressive complexity, fluently using classes/dataclasses."* Bank account is the running example (the canonical assessment substrate); analogies for each concept come from domains I actually know (sewing, knitting, choir).

## The learning loop
Each lesson follows the same steps:
1. **Read** a small piece of code
2. **Predict** what it will do — *before* running it
3. **Run** it and check what actually happened
4. **Reflect** in my own words on what I learned
5. **Ask** Claude inline if something doesn't make sense
6. **Write** — author a small variant from a blank cell (not just read it)
7. **Fix** — debug a deliberately broken version

Steps 1–5 build comprehension. Steps 6–7 are the authorship + debugging half —
"code well in Python" and "debug when things break."

## Goal
Reach research-script authorship + debugging fluency: write a working small program
from scratch, unaided, and fix it when it breaks. The memory system is the textbook —
I aim to *understand the whole system* and *author and debug its pieces*.
